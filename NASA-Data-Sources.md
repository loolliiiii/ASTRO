# NASA data and resources used in ASTRO

| What | Source | How ASTRO uses it |
|---|---|---|
| Mars Exploration Rover mission (Spirit & Opportunity) | NASA/JPL — https://science.nasa.gov/mission/mer-spirit/ and https://science.nasa.gov/mission/mer-opportunity/ | Mission dates, distances driven, how each mission ended |
| Hematite spherules ("blueberries"), Eagle Crater, Meridiani Planum | NASA/JPL Opportunity science results (2004) | Mini-TES, Microscopic Imager and Mössbauer field tasks |
| El Capitan outcrop: fine cross-bedded layers | NASA/JPL Opportunity science results (2004) | Pancam and Rock Abrasion Tool field tasks |
| Sulfur-rich salts showing past liquid water | NASA/JPL Opportunity science results (2004) | APXS field task |
| Rover instruments (Pancam, MI, Mini-TES, APXS, Mössbauer, RAT, Hazcams) | NASA/JPL MER instrument pages | Tool choices in every puzzle |
| Mars Exploration Rover artwork | NASA/JPL (public domain) | Rover image in the game |
| Planet textures (Mars, Earth, Venus, Jupiter, Saturn, Neptune) | NASA 3D Resources — https://nasa3d.arc.nasa.gov/ (public domain) | 3D planets |
| Planetary Data System (MER archive) | https://pds-geosciences.wustl.edu/missions/mer/ | Reference for rover science data |
